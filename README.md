# 🌤️ Simple Weather App

A lightweight and responsive **Weather Application** built using native web technologies. This project fetches and displays real-time weather details for any city globally by connecting to a third-party weather data service.

## ✨ Features
* **Global Search**: Fetch real-time weather information for any city worldwide.
* **Dynamic Details**: Displays temperature, humidity, wind speed, and atmospheric conditions.
* **Responsive Layout**: Fluid design optimized for mobile, tablet, and desktop viewports.
* **Visual Transitions**: Dynamic background changes or icon switching based on the retrieved weather state.

## 🛠️ Tech Stack
* **HTML5**: Structured semantic web page markup.
* **CSS3**: Layout styling with Flexbox/Grid and custom modern animations.
* **JavaScript (ES6+)**: Handles DOM manipulation, event listeners, and asynchronous API calls.
* **API Integration**: Powered by the OpenWeatherMap API (or alternative provider) via the native Fetch API.

## 📦 Installation & Setup
Follow these steps to run this application locally on your machine.

1. **Clone the Repository**
   ```bash
   git clone https://github.com
   cd YOUR-REPO-NAME
   ```

2. **Configure Your API Key**
   * Sign up at [OpenWeatherMap](https://openweathermap.org) to obtain a free API key.
   * Open your JavaScript configuration file (`script.js`).
   * Replace the placeholder string with your personal API token:
     ```javascript
     const apiKey = "YOUR_ACTUAL_API_KEY";
     ```

3. **Launch the Application**
   * Open the `index.html` file directly inside any web browser.
